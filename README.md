# Учёт заявок на ремонт телефонов «MyСмарт»

Настольное приложение для автоматизации работы сервисного центра по ремонту телефонов «MyСмарт», разработанное для исключения потери заказов и ускорения обслуживания клиентов (автор: Кузнецов Иван Евгеньевич, 12ТЭС; статус: завершён `v1.0`).

## Заказчик и проблема
Сервисный центр переходит от бумажного журнала учёта к цифровому решению, чтобы быстро находить данные по номеру заявки, контролировать статусы ремонта и избегать путаницы в описании поломок.

## Планируемая функциональность
- Создание заявок с автоприсвоением номера и статусом «Принят».
- Просмотр, поиск по номеру/модели и фильтрация списка.
- Пошаговое изменение статуса: **«Принят» → «В ремонте» → «Готов» → «Выдан»**.
- Редактирование данных, удаление с подтверждением и счётчик заявок по статусам в панели.

## Установка и запуск
1. Клонируйте репозиторий и перейдите в папку:
   ```bash
   git clone https://github.com
   cd student-project-template-kuznivan
   ```
2. Убедитесь, что установлен Python 3.11+ с поддержкой Tkinter.
3. Запустите приложение: `python src/main.py`.
