# \# Учёт заявок на ремонт телефонов «MyСмарт»

# 

# Вы работаете в компании «MySoft», которая разрабатывает небольшие приложения для бизнеса. К вам обратился заказчик \*\*MyСмарт\*\*. Он занимается ремонтом мобильных телефонов, но сотрудники сталкиваются с проблемой: заявки записывают на бумаге или в разрозненных заметках, из-за чего теряется информация о поломках, сложно быстро найти телефон клиента по номеру заявки и отследить текущий этап ремонта. Вам поручили разработать настольное приложение для учёта заявок на ремонт телефонов, чтобы ускорить приём и выдачу устройств и исключить потерю заказов.

# 

# \## Заказчик и проблема

# 

# \*\*MyСмарт\*\* — сервисный центр по ремонту смартфонов, где работают приёмщик и мастер по ремонту. Сейчас заявки фиксируются в бумажном журнале: при звонке клиента сотруднику приходится долго листать записи, чтобы узнать статус устройства, а при исправлении описания поломки возникают путаница и помарки.

# 

# \## Планируемая функциональность

# 

# \- Добавление новой заявки с автоматическим присвоением уникального номера, указанием модели телефона, описания поломки и начального статуса «Принят».

# \- Просмотр общего списка заявок и отображение данных выбранной заявки в форме.

# \- Изменение модели телефона и описания поломки с проверкой заполнения обязательных полей.

# \- Поиск заявки по номеру или модели телефона и фильтрация списка по статусу ремонта.

# \- Изменение статуса заявки строго по цепочке: \*\*«Принят» → «В ремонте» → «Готов» → «Выдан»\*\*.

# \- Удаление выбранной записи с обязательным окном подтверждения.

# \- Отображение счётчика заявок по каждому статусу в нижней панели окна.

# \## Установка и запуск

# 

# 1\. Склонируйте репозиторий и перейдите в его папку в терминале:

# &#x20;  ```bash

# &#x20;  git clone https://github.com

# &#x20;  cd student-project-template-kuznivan

# &#x20;  ```

# 2\. Убедитесь, что установлен \*\*Python 3.11 или новее\*\* с поддержкой стандартной библиотеки \*\*Tkinter\*\* (в Windows входит в стандартную установку Python). Внешние библиотеки не требуются.

# 3\. После создания файла `src/main.py` запустите приложение командой:

# &#x20;  ```bash

# &#x20;  python src/main.py

# &#x20;  ```

# \## Спринты разработки

# 

# 1\. \*\*Спринт 1 — первая рабочая версия.\*\* Выбор темы, заполнение устава, требований и ТЗ, проектирование интерфейса. Создание окна Tkinter с вводом данных, проверкой обязательных полей и добавлением заявок в список. \*\*Результат:\*\* можно добавить заявку и увидеть её в списке.

# 3\. \*\*Спринт 3 — готовый продукт.\*\* Реализация удаления заявки с подтверждением, подсчёта статистики по статусам, проведение ручных проверок, добавление скриншотов и выпуск версии `v1.0`. \*\*Результат:\*\* все функции работают стабильно, документация и тесты заполнены.
