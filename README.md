# Учёт заявок на ремонт телефонов «MyСмарт»

В репозитории содержится проект настольного приложения для учёта заявок на ремонт смартфонов (Python + Tkinter), разработанный в рамках учебного проекта. Полный текст разметки `README.md` с описанием функциональности, структуры проекта, инструкцией по запуску и спринтами вы можете найти в исходных материалах проекта.
