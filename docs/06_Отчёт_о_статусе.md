# Отчёт о статусе спринта

**Проект:** [название]. **Заказчик:** My[название]. **Автор:** [ФИО, группа].
**Версия документа:** [номер]. **Дата:** [дата].

Копируйте раздел отчёта в конце каждого спринта, сохраняя историю. При необходимости добавляйте промежуточный отчёт.

## Отчёт за спринт № [номер]

- Цель спринта: [какой результат планировали].
- Период: [даты]. Дата отчёта: [дата].
- Общий статус: [по плану / есть отклонение / работа заблокирована; причина].
- Сделано: [результаты, ссылки на Issues, коммиты или демонстрацию].
- В работе: [задачи и ожидаемые даты завершения].
- Проблемы: [что уже произошло → влияние → действие → ответственный].
- Риски: [что может произойти → вероятность и влияние → мера].
- План следующего спринта (для последнего — дальнейшие улучшения): [2–4 результата и сроки].
- Трудозатраты: план [ч], факт [ч]; причина отклонения [заполнить].
- Готовность: [выполненный объём / общий объём × 100%].

Пример расчёта: задачи оценены суммарно в 40 часов; приняты задачи на 10 плановых часов → готовность 25%. Частично выполненные задачи не засчитываются; после изменения объёма обновите знаменатель.

- Демонстрация: [что показали → кто проверил → что принято].
- Выводы: [что получилось → что мешало → одно улучшение на следующий спринт].
- Качество: [сколько проверок проведено, сколько пройдено, открытые ошибки].
- Нужное решение заказчика: [вопрос, варианты, крайний срок; либо «не требуется»].
