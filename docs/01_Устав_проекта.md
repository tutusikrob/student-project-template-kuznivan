# # Устав проекта

# 

# **Проект:** Учёт заявок на ремонт телефонов. **Заказчик:** MyСмарт. **Автор:** \Кузнецов Иван Евгеньевич, 12ТЭС.

# **Версия документа:** 1.0. **Дата:** 19.11.2026.

# 

# ## Цель и задачи

# 

# - **Цель:** создать настольное приложение на Python + Tkinter для сотрудников сервисного центра «MyСмарт», которое позволит регистрировать заявки на ремонт телефонов, отслеживать их статусы и находить нужную заявку по номеру или модели не более чем за 5 секунд на наборе из 10 демонстрационных записей.

# - **Задачи:** уточнить требования заказчика; определить структуру карточки заявки и макет окна; реализовать функции добавления, просмотра, поиска, редактирования, смены статуса и удаления; провести ручное тестирование и передать готовую версию `v1.0`.

# 

# ## Участники и границы

# 

# - **Заказчик:** сервисный центр «MyСмарт»; представитель — руководитель мастерской (роль выполняет преподаватель при приёмке).

# - **Пользователи и их интересы:** приёмщик заказов и мастер по ремонту — заинтересованы в быстрой регистрации поломок, прозрачном контроле этапов ремонта и исключении потери заявок.

# - **Исполнитель:** [Кузнецов Иван Евгеньевич]; роли — аналитик, руководитель проекта, разработчик, тестировщик.

# - **Входит в границы проекта:** добавление заявки с автономером, просмотр списка и карточки, редактирование с проверкой пустых полей, поиск по номеру/модели и фильтр по статусу, последовательная смена статуса («Принят» → «В ремонте» → «Готов» → «Выдан»), удаление с подтверждением, подсчёт заявок по статусам.

# - **Не входит в границы проекта:** подключение СУБД, обязательное сохранение данных после закрытия программы, SMS-уведомления клиентам, онлайн-оплата и мобильное приложение.

#
